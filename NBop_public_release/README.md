# NBop PROJECT 001 — DESIGNING A SHRINKING SOCIETY
Public release candidate / 2026

## Local preview
Node.js 22 recommended. Run `npm install`, then `npm run dev`. For production verification: `npm run build`, then `npm run preview`.

## GitHub → Vercel
1. Create a GitHub repository (e.g. `nbop-shrinking-society`). Upload the contents of this folder, not its parent. Commit the lockfile generated by npm install if possible.
2. In Vercel, Add New → Project → Import the repository. Framework: Vite; root: repository root; build: npm run build; output: dist. No environment variables needed.
3. Deploy, open the generated URL, and verify the checklist below before advertising it.
4. After choosing the permanent URL, add absolute canonical, og:url and og:image metadata to index.html. Use an original 1200×630 PNG for the social preview, stored in public/. Change twitter:card to summary_large_image.

## Before announcing
- Test all 10 chapters, automatic 40-second changes, regenerate, pause, keyboard navigation, research dialog and PNG download.
- Test desktop Chrome/Safari and mobile Safari/Chrome, portrait and landscape, reduced motion, and WebGL failure.
- Review research text: the supplied summaries are preserved; replace with approved full article if desired. Verify supporting citations for chapter-specific claims. Population source: https://www.ipss.go.jp/pp-zenkoku/j/zenkoku2023/pp_zenkoku2023.asp
- Confirm public credits, any copyright notices, final domain, and social sharing image.
- No analytics, personal data collection forms, or additional service credentials were added.

## Notes
Three.js is pinned at 0.170.0 and bundled by Vite, avoiding a third-party CDN fetch at runtime. Artwork is abstract, not geographic simulation. The index animation is a linear interpolation of the two population endpoints, not annual projections. The original V06.1 art builders and research text are retained.
